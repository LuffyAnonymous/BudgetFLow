# Milestone 3: Debts & Savings (Planning Phase)

Milestone 3 will implement debts management, payment history, rollover fee projections, and savings tracking.

## Goals

### 1. Debts Management
* Support multiple debts.
* Perform payment recordings that:
  - Update debt current balance.
  - Create a debt payment log.
  - Optionally create a linked ledger transaction.
* Estimate rollover fee projections without writing values to actual balances.

### 2. Savings Management
* Support multiple savings goals.
* Perform deposit and withdrawal recordings that:
  - Update saving goals current amounts.
  - Create a saving transaction log.
  - Optionally create a linked ledger transaction.

### 3. Dashboard Integration
* Replace placeholder cards on the dashboard with outstanding debt, monthly target goals, and progress scales.
